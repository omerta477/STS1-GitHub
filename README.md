Projet TD GitHub en C++

Dans ce projet, on doit coder plusieurs fonctions en C++.
Les fonctions sont écrites dans TD_GitHub.h et on doit les compléter dans TD_GitHub.cpp.

Étudiant 1 :
	•	estMajeur : Il dit si une personne est majeure
	•	exposant : calcule une puissance sans utiliser pow
	•	TVA : ajoute une TVA selon le prix
	•	plusGrand : trouve le plus grand nombre

Étudiant 2 :
	•	estPair : dit si un nombre est pair ou divisible par 7
	•	sommeNombre : fait la somme des nombres jusqu’à un nombre donné
	•	salaireNet : calcule un salaire avec charges et prime
	•	plusPetit : trouve le plus petit nombre

Étudiant 3 :
	•	estImpair : dit si un nombre est impair ou divisible par 8
	•	moyenne : calcule la moyenne de 3 nombres
	•	reduction : applique une réduction puis une TVA
	•	nombreMedian : trouve le nombre du milieu
